# Password Strength Checker

A beginner-friendly password strength checker built in Python using only basic concepts (no imports or external libraries).

> **Note:** This project is built entirely using Python basics.
> I made it to practice and strengthen my fundamentals.

## Features
- Checks password length
- Checks for uppercase, lowercase, numbers and special characters
- Gives a score out of 6 and a final rating (Weak / Medium / Strong)

## Concepts used
- Variables and data types
- `input()` and `print()`
- `if / elif / else`
- `for` loop
- String methods (`isupper()`, `islower()`, `isdigit()`)
